# 弱点補強プリント

答案（教科書ワーク・プリント・テスト）の写真から、間違えた問題をAIが抜き出してミスを分類し、類題の弱点補強プリント（A4一枚）と、別紙の解答・解説を作ります。中1〜中3の5教科に対応しています。

## 使い方

1. **写真**：生徒名・学年を入れ、答案の写真を撮影または選択します（最大10枚）。
2. **確認・分類**：AIが読み取った「間違えた問題」を確認します。問題文・答えの修正、ミスの分類（A〜F）の変更、類題の数（1〜3問）の指定ができます。
3. **プリント**：A4の問題用紙と解答・解説が表示されます。「印刷 / PDF保存」で印刷できます。

### 採点記号のルール

- ○ がついている問題 → 正解
- ✗・✓ がついている問題、○ がついていない問題、空欄 → 間違い

### ミスの分類

| | 分類 | 対策 |
|---|---|---|
| A | 計算・スペルなどのミス | 見直し1回 |
| B | 見まちがい・写しまちがい | 指さし確認 |
| C | とばし・見落とし | 途中を書く |
| D | 問題の読みまちがい | 2回読む |
| E | 習っていない・忘れた | 先生に聞く |
| F | 使い方が思いつかない | 先生に聞く |

A〜D は「自分でへらせるミス」として、類題に対策の一言（☝）をつけます。E・F は「先生に聞く」ミスとして、公式や考え方のヒント（💡）をつけた基本問題・段階的な問題にします。

## ローカルで起動する

1. `.env.example` をコピーして `.env` にし、APIキーを貼り付ける
2. 次のコマンドで起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3002` を開いてください。

## Render にデプロイする

1. このリポジトリを Render の **New → Web Service**（または Blueprint）で接続します。`render.yaml` の設定が読み込まれます。
2. **Environment** に次を設定します。

| Key | Value |
|-----|-------|
| `ANTHROPIC_API_KEY` | Anthropic の APIキー |
| `APP_PASSWORD` | 任意。設定すると、開くときにパスワードを聞かれます（URLを知った人に使われないように、設定をおすすめします） |

> APIキーは絶対にコードに直接書かないでください。

## 必要なもの

- [Anthropic APIキー](https://console.anthropic.com/)（Claude Opus 5.5 を使用）
- Node.js 20.12 以上（ローカル起動の場合）
